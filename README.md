# Скрипт для очистки CSV

Скрипт для обработки CSV-файлов: удаление дубликатов, пустых строк и фильтрация данных по заданному условию.
Стек: Python, pandas.

Как запустить:

Установите библиотеку: pip install pandas
Положите файл input.csv в папку со скриптом.
Запустите: python csv_cleaner.py
Результат будет в файле output.csv.
